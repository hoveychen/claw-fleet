On Linux, download the binary for your processor, then run:+
chmod +x fleet-linux-x64
./fleet-linux-x64 webui

Open http://127.0.0.1:4571 in your browser. For ARM64, replace x64 with arm64 in both commands.

On Android, the APK installs directly — Claw Fleet is not distributed through an app store.+

Allow “install unknown apps” for whatever opens the file, then pair the phone by scanning the QR in the desktop app under Settings → Devices. The phone is a companion to a desktop workspace, not a standalone app.

Get your workspace ready.

  1. Connect your AI tools

    Check or install the tools from Settings, then sign in or fill in provider credentials. Model subscriptions and API usage stay on each vendor’s own bill.

  2. Hand over the first idea

    Write what you want done, pick a project, a tool and a model, attach material if you have it. The coordinator takes it from there.

  3. Take it with you

    Pair your phone under Settings → Devices. As long as the machine running Fleet stays online, decisions reach you anywhere.

A few things to know.

Which AI tools can I use?+

Fleet connects to Claude Code, Codex and DeepSeek Harness (the @deepseek-ai/dsh CLI). Install and configure the tools you want to use. DeepSeek Harness can select models from configured providers; availability depends on those providers and your credentials. Which agent tools Fleet works with keeps the tool list and the model list apart.

I already use the Claude Code CLI. What does Fleet add?+

A coordinator per idea instead of a pile of terminals: one conversation that splits work into sub-tasks after you confirm, waits for them and reports back; every task across every project on one page; and one queue for the calls that need you, with the material attached. It starts the CLI you already have and reads the sessions it writes. A desktop workspace for Claude Code walks through it.

I use Codex, not Claude Code. Does that work?+

Yes — a task picks its tool when you brief it, and Codex tasks get its own model catalogue, its own reasoning ladder and the ChatGPT-plan windows it reports. A desktop workspace for Codex goes through it.

Can I use my own provider keys instead of a subscription?+

That is what DeepSeek Harness is for: you configure the providers, and the models you can reach are whatever those keys open. A desktop workspace for DeepSeek Harness covers how spend and effort work there.

Is it free?+

Claw Fleet itself is free and open source under AGPL-3.0. AI tools, model subscriptions and API usage stay on each vendor’s own bill. Costs shown in Fleet are estimated from usage, for reference only.

Does my computer have to stay on?+

The machine running the task has to stay online. If your phone is paired to Fleet on your computer, that computer and Fleet both need to be up. You can also deploy fleet webui on a machine that stays on.

Can I speak to it from my phone?+

Voice input transcribes speech into text that you can edit before sending. Availability depends on your browser or device speech service and microphone permission. It is not a two-way voice call.

Are all results saved automatically?+

The deliverables view contains files added by an agent or the artifact command. Supported files can be previewed and exported. Mobile relay previews have a 16 MiB limit; use the desktop for larger files.

What happens on a long task?+

It stays one task. The coordinator keeps a step list, splits parallel work into sub-tasks, can wait on a build or a sub-task without holding a session open, and continues in a fresh context when one fills up — on the same tool or another. That is not unlimited context, and what you can use depends on the tool’s support.

Where does my data go?+

Fleet runs on your machine and reads local session data. AI tools connect to their configured providers. Phone access uses a relay when paired with a desktop; self-hosting is also possible. Fleet does not include a model account or a hosted cloud workspace subscription.

How do I download in China?+

When a China mirror is enabled, select it above. GitHub Releases remains the alternative. The Android APK is served from GitHub Releases; whether the mirror carries it depends on the release you are downloading. There is no iOS or HarmonyOS package yet — on those, open the pairing link in the browser.
