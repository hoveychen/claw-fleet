写给已经在用 Claude Code 的人

命令行你已经有了。
这一页讲它外面那一圈。

Claude Code 跑在终端里，一次一个会话，而每个会话都不记得自己所在的那个「房间」。Claw Fleet 是一个桌面应用，替你把房间留着：任务属于哪个项目、正卡在哪个决定上、走到计划的第几步、产出了哪个文件。活还是 CLI 干的——Fleet 是它干活时你看的那一面。

同时开着三个的时候

开两个终端没问题。开到四个，照看它们本身就变成了工作：你在窗格之间来回切，就为了看哪个跑完了、哪个卡住了、哪个在等你。

Fleet 把它们放在同一块板上。每个任务挂在自己的项目下，卡片上标着用的哪个工具、哪个模型；哪些在思考、哪些在执行命令、哪些停下来问话，一眼能分清。发起任务只有一个入口，任务还在跑时可以追加一句指令，跑完之后还能接着聊。

这块板是你真实会话的一个视图，不是它们的副本：Fleet 读的就是 Claude Code 本来就在写的 transcript，所以你在终端里起的会话也会出现在这里。

它问你能不能继续的那一刻

在终端里，这个问题是一句没有上下文的提示：它要你对一份方案表态，而那份方案得你自己往上翻才看得到。

Fleet 把这些时刻收进同一个队列，并且把材料贴在上面。一份可以先改再批的方案。agent 刚生成的图片。它写的 HTML 报告。一条有风险的命令，连着风险分析，在执行之前。你先看清要决定的东西，再用选项、表单字段或者一句话回答，答案回到提问的那个任务。

每一个问题、你的选择、你补的那句话，都跟着这件活留着，所以上周的一个决定，今天还能和它产出的东西并排读。

挑模型，也挑它想多久

交代任务时你就选模型，来自 Claude Code 自己的目录——Fable 5.1 与 Fable 5、Opus 5 与 Opus 4.8、Sonnet 5 与 Sonnet 4.6、Haiku 4.5——推理档位一并选，就是 CLI 接受的那五档：low、medium、high、xhigh、max。权限模式在同一个输入器上，所以「这件事我想让它自己跑完」和「这件事我要一步步过」是两次不同的选择，而不是两套不同的配置。

模型订阅与 API 用量仍在你自己的 Anthropic 账号上，和现在完全一样。Fleet 读你会话消耗了多少，把 token、估算费用、输出速度和配额窗口摊给你看——你看到的是自己的用量，不是我们开的账单。

agent 执行过的命令会按风险类别记录下来。那和逐条批准是两件事：它是事后你去读的那份记录。

做完的东西落在哪

一个长会话会产出实物：一份文档、一张表、一段渲染好的图、一份值得读第二遍的报告。在终端里，它们最后是一串你得自己记住的路径。

Fleet 按项目留一个产出视图，PDF、Office 文件、图片、视频与网页文档都能就地预览。收藏一个、给自己留句备注、导出文件、一个月后再回来找。值得复用的结论进版本化的项目知识库，后面的会话可以搜、可以引——包括跑在另一个工具上的会话。

落进去的是 agent 添加的、或者 artifact 命令收进来的东西，不是把你碰过的一切扫进来。

长活，以及把一件活交出去

要做一整天的活，装不进一个会话。Fleet 给这个形状留了地方：一个计划，步骤做完就勾掉；一次交接，从一份简报起一个全新会话，并把计划、停在第几步、以及前任留下的笔记一起带过去；还有一条事后能回溯的接力链。

重复的活挂到日程上。在等什么的活——一次构建、一次部署、一个队列——就等那个条件满足了再起 agent，而不是把一个会话一直挂着。

交接时可以指定另一个工具的模型，下一棒就跑在那边。计划、知识库和产出属于这件活本身，而不属于生成它们的那个 CLI。

你的 Claude Code 配置仍然是你的

Fleet 不接管你的配置。它读的就是 CLI 读的那些目录，所以你的 CLAUDE.md、skills、plugins 与记忆规则仍然是会话真正在用的那份——Fleet 只是让你有地方翻它们、看一条规则的修订历史、把 skills 同步到支持它的工具上。

它跑在你自己的机器上，紧挨着 CLI。跑任务的那台机器要在线，这件活才动得了；这也正是手机端有用而不是「又一处要配置的地方」的原因：手机和桌面配对之后，你在哪都能交代任务、追加一句指令、回答一个决定、预览一个产出，而活仍然发生在你自己的电脑上。

Fleet 本身免费开源，协议是 AGPL-3.0。它不自带模型账号，也没有托管订阅——你接上的是你已经有的工具和账号。

大家先问的几个问题

它是要替掉 Claude Code 命令行吗？+

不是。Fleet 起的就是你装好的那个 CLI，读的是它写下的会话数据。你在终端里起的会话会出现在 Fleet 里，Fleet 起的也是普通的 Claude Code 会话，你照样能在终端 resume。

需要 API key 吗？要另外订阅吗？+

我们这边都不需要。你照原来的方式登录 Claude Code，模型用量仍记在那个账号上。Fleet 自己免费开源；它显示的费用是按用量估算的，仅供参考。

我现有的 CLAUDE.md、skills 和 plugins 还能用吗？+

能——它们在你自己的配置目录里，Fleet 是读它们而不是替换它们。它还给你一个地方去查 skills、plugin 来源与记忆规则，包括一条规则来自哪一层作用域。

它还支持哪些 agent 工具？+

Claude Code、Codex 与 DeepSeek Harness，各自用各自的模型与账号。任务在交代时选定工具，一次交接可以把活从一个工具挪到另一个。
