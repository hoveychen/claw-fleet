写给已经在用 Codex 的人

Codex，
加一个安放工作的地方。

Codex 擅长长时间无人值守地干活，而那恰恰是终端最不告诉你事情的时候。Claw Fleet 是一个桌面应用：它起你的 Codex CLI、跟着它在干什么、并且给这次运行一个可以回头汇报的地方——计划、问题和做完的文件，都在你找得到的位置。

它自己的模型，它自己的档位

输入器上给的是 Codex 的目录，不是一份通用清单：GPT-6 Astra，GPT-5.6 的 Sol、Terra、Luna 三档，以及 GPT-5.5。推理档位按 Codex 自己的刻度——minimal、low、medium、high——只有 Astra 例外：它不收 minimal，反而多出更深的 xhigh 与 max。Fleet 显示的是那个模型真正接受的档位，所以选择器不会递给 Codex 一个它会拒绝的值。

档位是按任务传的，不写进你的配置，所以你原来在 Codex 里留的 profile 照样生效，而这一件活可以比下一件想得更久，你什么都不用改。

Codex 没有 Claude 那套权限模式，Fleet 也不假装有：Codex 任务上那颗按钮直接不出现。

它上报的配额窗口，画成图

Codex 记在你的 ChatGPT 套餐上，并且会上报自己的限流窗口。Fleet 把每次上报记下来、按时间画出来，于是「这一周用得很猛」是一件你能看见的事，而不是等某次运行停下来才发现的事。

不同套餐上报的形状不一样——Team 套餐给的是单个 7 天窗口，别的给两个——图跟着你账号实际上报的走，而不是假定一种布局。

旁边还有：每个会话的 token、估算费用、实时输出速度。估算只用来对个数量级，不是账单；套餐本身仍是你和 OpenAI 之间的事。

无人值守的运行，也能问你一句

无人值守最难的一刻是它需要一个人。`codex exec` 那种运行没有交互通道能找到你，所以过去它要么停下，要么自己猜。

Fleet 把自己注册成那次运行可以调用的一个工具，于是「问一下操作者」变成了落在你桌面和手机上的一张决策卡：一个问题、几个真实选项、答案有字段时给一张表单，以及贴在上面的材料——一份方案、一张图、一份 HTML 报告。你的回答再回到同一次运行里。

它进的是和其他工具同一个队列，所以一次 Codex 运行在等你，看起来和别的在等你的事一样。

让 Codex 画张图

Codex 自带一个图像生成 skill，背后是 gpt-image-2，同样记在那个 ChatGPT 套餐上。Fleet 借用它：一个任务可以要一张插画、一张 mockup 或者一张主视觉，拿回来的是落进项目里的文件——而这件事 Claude 那边根本做不到。

图片也能反过来走。给简报附上参考图，它们是以真实文件的形式送到那次运行手里的，不是一段对图片的描述。

计划走到一半，换个工具接手

计划与交接不属于某一个工具。Codex 会话里写下的计划，就是 Claude Code 会话接手的那一份；交接会带上停在第几步，以及前一棒留下的笔记。

所以分工可以顺着各自擅长的来——一个拆方案、一个实现、一个复审——而且是每件活各自决定，不必把整套工作流押在一家供应商身上。项目知识库和产出跟着这件活，下一个工具照样读得到。

定时与条件触发也一样：一次夜间巡检、一个在等构建的活，可以是 Codex 任务，而不必因此变成一套只跑 Codex 的配置。

它跑在哪，花谁的钱

Fleet 在你自己的机器上起 Codex CLI，读它写下的会话文件，所以你在终端里起的运行也会出现在 Fleet 里，而 Fleet 起的仍然是一个普通的 Codex 会话。那台机器要在线，它的任务才动得了；手机连回来的也正是这台机器。

Fleet 本身免费开源，协议是 AGPL-3.0。它不自带模型账号，也没有托管订阅——Codex 的用量仍记在你已经在付的那个 ChatGPT 套餐上。

大家先问的几个问题

Fleet 需要 OpenAI API key 吗？+

不需要。它起的是 Codex CLI，鉴权照你原来配好的方式走——对多数人来说那是 ChatGPT 套餐而不是 API key。Fleet 不额外引入任何账号。

我原来的 Codex profile 和配置还能用吗？+

能。Fleet 读的就是 CLI 用的那个 Codex home 目录。你为某个任务选的模型或档位只对那个任务生效；你没覆盖的部分仍来自你自己的配置。

Codex 任务能把活交给 Claude Code 吗？+

能——交接时可以指定另一个工具的模型，计划、笔记和产出会一起过去。把这些放在 Fleet 而不是某一个 CLI 里面，就是为了这个。

它能驱动哪些 Codex 模型？+

你账号能触达的那些，来自 Codex 自己的目录：GPT-6 Astra、GPT-5.6 的 Sol / Terra / Luna，以及 GPT-5.5。能用哪些取决于你的套餐，不取决于 Fleet。
