你可能还想知道。

可以接哪些 AI 工具？+

Fleet 接入 Claude Code、Codex 和 DeepSeek Harness（命令行工具 @deepseek-ai/dsh）。使用前需要安装并配置对应工具。DeepSeek Harness 可选择已配置提供商的模型；具体可用性取决于提供商和你的凭证。Fleet 能接哪些 agent 工具这一页把工具清单和模型清单分开讲。

我已经在用 Claude Code 命令行了，Fleet 多给我什么？+

一个想法一个统筹，而不是一堆终端：一条对话在你确认后把活拆成子任务、等它们做完再向你汇报；所有项目的所有任务都在一页；需要你拍板的事汇进一个队列，材料附在旁边。它起的就是你已经装好的那个 CLI，读的是它写下的会话。Claude Code 的桌面工作台这一页讲得更细。

我用的是 Codex 不是 Claude Code，也行吗？+

行——任务在交代时选定工具，Codex 任务用的是它自己的模型目录、自己的推理档位，以及它上报的 ChatGPT 套餐配额窗口。Codex 的桌面工作台这一页讲得更细。

我能用自己的 provider key 而不是订阅吗？+

DeepSeek Harness 就是干这个的：provider 由你配，能用到哪些模型取决于那些 key 打开了什么。DeepSeek Harness 的桌面工作台讲了那边的花销与档位是怎么算的。

需要付费吗？+

Claw Fleet 本身免费开源，采用 AGPL-3.0 协议。AI 工具、模型订阅和 API 用量按各家自己的账单走。Fleet 里显示的花费是按用量估算的，仅供参考。

电脑需要一直开着吗？+

跑任务的那台机器需要保持在线。手机配对的是你的电脑，就得让电脑和 Fleet 都开着；也可以把 fleet webui 部署到一台常年在线的机器上。

手机可以用语音吗？+

语音输入会转成文字，发送前可以修改。是否可用取决于浏览器或设备的识别服务，以及麦克风权限；不是双向实时语音通话。

所有结果都会自动保存吗？+

产出页展示由助手或产物命令加入的文件，支持的格式可以预览与导出。手机经由中继预览单文件上限为 16 MiB，更大的文件请在桌面处理。

做很长的任务怎么办？+

它始终是同一个任务。统筹维护一份步骤清单，能并行的拆成子任务，等构建或等子任务时不用占着会话，上下文写满了就在新的上下文里接着做——同一个工具或换一个都行。这不等于无限上下文，具体能用到哪些取决于那个工具的支持程度。

我的数据会去哪里？+

Fleet 在你自己的电脑上运行，读取本机会话数据，AI 工具连接各自配置的提供商。手机配对桌面时经由中继访问，也支持自建中继。Fleet 本身不包含模型账号或托管云工作台订阅。

国内怎样下载？+

下载区开通国内镜像后，可以选择国内线路，GitHub 官方发布作为备用。Android 安装包由 GitHub 发布页提供，是否进国内镜像取决于你下载的那个版本。iOS 与鸿蒙暂无安装包，请在浏览器里打开配对链接。
