你可能还想知道。

可以接哪些 AI 工具？+

Fleet 接入 Claude Code、Codex 和 DeepSeek Harness（命令行工具 @deepseek-ai/dsh）。使用前需要安装并配置对应工具。DeepSeek Harness 可选择已配置提供商的模型；具体可用性取决于提供商和你的凭证。

需要付费吗？+

Claw Fleet 本身免费开源，采用 AGPL-3.0 协议。AI 工具、模型订阅和 API 用量按各家自己的账单走。Fleet 里显示的花费是按用量估算的，仅供参考。

电脑需要一直开着吗？+

跑任务的那台机器需要保持在线。手机配对的是你的电脑，就得让电脑和 Fleet 都开着；也可以把 fleet webui 部署到一台常年在线的机器上。

手机可以用语音吗？+

语音输入会转成文字，发送前可以修改。是否可用取决于浏览器或设备的识别服务，以及麦克风权限；不是双向实时语音通话。

所有结果都会自动保存吗？+

产出页展示由助手或产物命令加入的文件，支持的格式可以预览与导出。手机经由中继预览单文件上限为 16 MiB，更大的文件请在桌面处理。

做很长的任务怎么办？+

Fleet 提供计划、交接、日程和条件等待四种手段。交接是带着简报开一个新会话接着做——可以换成另一个 AI 工具接手，但它不等于无限上下文。具体能用到哪些，取决于你的配置和那个工具的支持程度。

我的数据会去哪里？+

Fleet 读取本机会话数据，AI 工具连接各自配置的提供商。手机配对桌面时经由中继访问，也支持自建中继。Fleet 本身不包含模型账号或托管云工作台订阅。

国内怎样下载？+

下载区开通国内镜像后，可以选择国内线路，GitHub 官方发布作为备用。手机目前可以从 Fleet 的配对链接进入；这里的下载不包含原生手机应用安装包。
