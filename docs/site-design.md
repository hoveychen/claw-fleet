# Claw Fleet 消费者官网改版

## 用户与主线

面向已经使用 Claude Code / Codex 的个人开发者、小团队：安装 Fleet 后把并行任务、待答问题和手机控制放在一起。结构为价值主张 → 可操作的产品示例 → 三个使用情境 → 下载 → 上手与 FAQ。中英文独立 HTML，共享 CSS / JS，不依赖 JS 翻译、Google 字体、GitHub API 首屏请求或远端图片。

## 参考与边界

参考用户指定的 ChatGPT / Codex 官网体系：清楚的消费者表达、充足留白、产品主视觉、短而具体的使用场景、明确的下载入口。2026-09-07 实际请求 https://chatgpt.com/overview/ 与 https://openai.com/codex/ 均遇到 403；隔离浏览器也停留在 Cloudflare 验证页。因此不宣称完成当前官网的逐页视觉审计，也不复制它们的版式、商标或文案。

## 视觉方案与自审

颜色：canvas #ffffff、ink #202222、muted #606968、line #dce0df、stage #deebf1、action #245b47。字体：Avenir Next / Segoe UI / PingFang SC / Microsoft YaHei 系统本地字体栈；标题与正文同家族，用尺度区分。布局：左侧大标题、右侧简介，下面一整幅产品舞台；交替宽图文场景，下载用可比较的横向列表。

签名元素：可切换的工作台演示，从「看任务」切到「做决定」和「接续任务」，让访客亲自理解产品。所有示例标识为示例，不冒充实时运行。现有截图含演示数据，以图注说明。

自审：舍弃旧页的奶油底、衬线标题、陶土强调色与悬浮拼贴，也舍弃常见的居中标题加三卡片结构。只在产品舞台集中视觉注意力，其他区域保持平静；无滚动揭幕、无渐变、无外部字体，无编造客户评价、增长数字或未验证的平台支持。Windows 标为 x64 安装包，不能把同一资产描述成原生 ARM64。

## 国内分发证据（2026-09-07）

- 当前 GitHub latest：v2.6.0；macOS 70,734,592 B，Windows x64 32,482,625 B，Linux x64 / ARM64 各约 28 / 26 MB。
- Gitee 官方 https://help.gitee.com/repository/release/create ：普通单附件 <=100 MB、仓库附件总量 <=1 GB（包括发行版附件）。当前能装下，保留多版本很快触顶。适合作为国内项目与补充分发入口。
- 腾讯云 COS 官方 https://cloud.tencent.com/document/product/436/14984 ：支持静态网站、目录索引、HTTPS、自定义域名。2024-01-01 之后的桶不能依赖默认域名作公开官网，需自定义域名。选择大陆地域时需按域名接入要求办理备案；香港地域可先部署，但不能把跨境连接宣称为大陆加速。
- 推荐腾讯云 COS 承载官网及不可变版本下载文件；GitHub Release 继续是版本来源。同步脚本从真实 Release 读取文件，校验 SHA-256，上传所有包后再更新下载清单。页面保留 GitHub 备用入口，未配置国内域名时不出现假镜像按钮。
- CNB 文档首页 https://docs.cnb.cool/zh/ 可访问，但本次未证实公开下载稳定地址、配额及匿名下载链，因此不当作已验证替代。
